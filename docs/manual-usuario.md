# Manual de Usuario — Agencia Monarca Web

# Inicio

La plataforma permite explorar paquetes vacacionales y realizar reservaciones en línea.

---

# Cómo explorar paquetes

1. Ingresar al sitio web.
2. Acceder a la sección de paquetes.
3. Consultar información del destino.
4. Revisar precios y disponibilidad.

---

# Cómo realizar una reservación

1. Seleccionar un paquete vacacional.
2. Completar el formulario de reservación.
3. Verificar la información ingresada.
4. Enviar la reservación.

---

# Pago Manual

Después de realizar la reservación:

1. El usuario deberá contactar a la agencia.
2. El pago será realizado manualmente.
3. El administrador actualizará el estado del pago.

---

# Contacto

El usuario podrá comunicarse mediante:
- Formulario de contacto
- Teléfono
- Redes sociales
