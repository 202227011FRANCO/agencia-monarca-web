# Requerimientos del Proyecto — Agencia Monarca Web

## Objetivo General
Desarrollar una plataforma web tipo MVP para una agencia de viajes, enfocada en la visualización de paquetes vacacionales, reservaciones y administración básica de clientes.

---

# Alcance del MVP

El sistema permitirá:

- Explorar paquetes vacacionales
- Consultar información de destinos
- Realizar reservaciones
- Contactar a la agencia para completar pagos manuales
- Administración básica desde panel administrativo

---

# Módulos Incluidos

## Frontend Público
- Página Home
- Vista de paquetes
- Formulario de contacto
- Diseño responsive

## Reservaciones
- Formulario de reservación
- Registro de reservaciones
- Validación básica de disponibilidad

## Administración
- CRUD de paquetes
- Gestión de reservaciones
- Estados de pago
- Gestión básica de clientes

---

# Requerimientos Funcionales

## RF-01
El sistema debe mostrar una página principal responsive.

## RF-02
El sistema debe listar paquetes vacacionales disponibles.

## RF-03
El usuario debe poder consultar información detallada de paquetes.

## RF-04
El usuario debe poder realizar una reservación.

## RF-05
El sistema debe registrar estados de pago manuales.

## RF-06
El administrador debe poder crear, editar y eliminar paquetes.

## RF-07
El administrador debe poder visualizar reservaciones.

## RF-08
El sistema debe incluir formulario de contacto funcional.

---

# Requerimientos No Funcionales

## RNF-01
El sistema debe ser responsive.

## RNF-02
Las páginas deben cargar en menos de 3 segundos.

## RNF-03
Las rutas administrativas deben estar protegidas.

## RNF-04
El código debe mantenerse organizado y modular.

## RNF-05
Compatibilidad con navegadores modernos.
